## Special update instructions

### Shader packs

1. Update using packwiz
2. Edit the shader pack name in default configuration for Iris
3. Rename the default configuration file in config/yosbr/shaderpacks

### Resource packs

1. Update using packwiz
2. Rename the resource pack in `options.txt` in config/yosbr/options.txt

# [secret's Pack](https://modrinth.com/modpack/secrets-pack) Source Code

The pack you have just downloaded and opened isn't a real modpack. _Installing it will not add any mods_. To find an installable copy of this modpack, go to <https://modrinth.com/modpack/secrets-pack> and download one of the releases.

Instead, this zip file contains the original files that were used to build the pack. The folder adjacent to this file is left unmodified from when the pack was exported by [packwiz](https://packwiz.infra.link/). Running `packwiz mr export` should yield you the same mrpack file as this version's main file.
